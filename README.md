# EcoDash – African Digital Logistics Simulator

## Project Overview

EcoDash is a browser-based logistics simulation game developed using HTML5 Canvas, CSS3 and Vanilla JavaScript.

The player controls a solar-powered delivery vehicle and delivers supplies across an African-inspired environment while managing battery energy and avoiding infrastructure and environmental challenges.

The project demonstrates JavaScript animation, trigonometric movement, velocity, acceleration, collision detection, environmental effects, scoring and local storage.

---

## African Context

EcoDash represents some of the challenges that can affect transportation and logistics in African environments.

The game includes:

- Potholes
- Flooded roads
- Fallen trees
- Construction zones
- Wildlife crossings
- Load-shedding
- Solar microgrid charging stations
- Wind
- Heavy rain and reduced visibility

The player must navigate these challenges while completing deliveries and managing the vehicle's available energy.

## How to Run the Game

1. Open the EcoDash project folder.
2. Open `index.html` in a modern web browser.
3. Click **Start Game**.
4. Use the arrow keys to control the delivery vehicle.
5. Use the `P` key to pause or resume the game.

The game is also deployed online using GitHub Pages.
